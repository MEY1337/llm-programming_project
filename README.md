# PDF 기반 AI 학습 도우미

대학생이 PDF에서 필요한 정보를 찾고 핵심 내용을 요약하며 두 문서를 비교하도록 돕는 RAG 프로젝트다. 문서명·페이지 근거 표시와 근거 부족 안내를 목표로 한다. 앱은 아직 구현되지 않았다.

## 현재 상태와 준비
2026-10-27 기준 P1 초기 결정은 확정됐고 P2 하네스 문서를 작성했다. 개인의 최종 채택은 대기한다. P3~P5는 수행하지 않는다.
Python 3.11, 로컬 Windows PowerShell 환경을 기준으로 준비할 예정이다. 도구·라이브러리 선택은 [ADR-0001](docs/decisions/0001-toolchain.md), 자료·키·비용 정책은 [결정 목록](docs/decisions/README.md)을 따른다.
아직 의존성 명세·잠금·가상환경·샘플·앱 진입점이 없다. 설치·키 입력·외부 연결 없이 문서를 검토할 수 있다.

## 실행·검사 명령
| 용도 | P2 실제 확인 결과 | 명령 |
|---|---|---|
| 설치·환경 동기화 | 명세·잠금 파일 없음, 미구성·미검증 | 미구성 |
| 앱 실행 | 소스·진입점 없음, 미구성·미검증 | 미구성 |
| Ruff 정적 검사 | 설정·환경 없음, 미구성·미검증 | 미구성 |
| pytest | 테스트·환경 없음, 미구성·미검증 | 미구성 |

P2에서 실제 파일 존재와 문서 링크를 확인한 뒤 이 상태를 기록했다. 실행 가능한 앱 명령은 확인되지 않아 기재하지 않았다. 향후 구성이 허용된 단계에서 명령을 실제 실행한 뒤 작업 디렉터리·필요 환경·결과와 함께 갱신한다. 문서 검사 통과는 앱 실행·테스트 성공을 의미하지 않는다.

## 미정과 제한
의존성 버전, 로컬 저장 경로·삭제 절차, 샘플 내용, 평가 세부 채점 기준은 후속 구체화 대상이다. 유료 호출 예산은 0원이며 키 연결·API 호출은 보류다. 현재는 문서만 있으며 데이터 제외 규칙도 기술적으로 구성하지 않았다.
