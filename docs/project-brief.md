## P2 하네스 문서 상태

사용자 후속 요청으로 P2 범위가 AGENTS.md, README, workflow, 테스트 계획, 결정 기준 및 ADR 작성·문서 검사로 구체화됐다. P1 당시의 ‘P2 미정·미착수’ 상태를 이 기록으로 갱신한다. 오늘의 작업 상한은 P2이며 P3~P5와 실제 앱 기능 구현은 진행하지 않는다.

문서별 기준 정보: [README](../README.md)는 준비·명령 상태·탐색, [AGENTS.md](../AGENTS.md)는 빈번한 작업 규칙, [workflow](workflow.md)는 역할과 절차, [testing](testing.md)은 검사 전략, [ADR 목록](decisions/README.md)은 채택 정책의 상세 기준이다. 이 개요는 요구·원문 근거·현재 상태를 관리한다. Q1~Q5 표는 초기 결정 요약이고 상세 정책 변경은 ADR에서 관리한다.

P2 문서를 작성했으며 개인의 최종 채택은 대기한다. 설치·환경 구성·PDF 제작·API 호출·앱 구현은 수행하지 않았다. 명령 미구성과 문서 검사 결과는 README와 testing을 참고한다.
