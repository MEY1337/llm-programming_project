# ADR-0005: 로컬 데이터 보관과 삭제

- 상태: 확정
- 결정자: 개인(프로젝트 사용자)
- 날짜: 2026-10-27
- 근거: Q5 A; 제안서 §3.1·§4.1, 사용자 A안 채택 답변. [초기 질문 기록](../open-questions.md)

## 배경
로컬 Chroma와 임베딩 재사용 계획에는 경로·보관·삭제 정책이 없었다.

## 선택지
A: 개발 PC Git 제외 경로에 보관·종료 시 삭제 / B: 세션마다 삭제 / C: 별도 경로·기간 지정

## 선택한 이유
임베딩 재사용으로 비용을 줄이고 저장소 노출을 제한하려고 A를 채택했다.

## 영향
원본·추출문·Chroma는 개발 PC의 Git 제외 경로에서 보관·재사용하고 개발 종료 시 삭제한다. 비민감 평가 결과만 별도로 기록한다. 캐시·대화/평가 로그 등 파생 자료도 같은 민감도 관점에서 관리하고 불필요한 본문 기록을 피한다. 구체 경로·종료 시점의 달력 날짜·삭제 절차는 후속 구체화 대상이다. 현재 저장소 제외 설정이나 자동 삭제는 구현되지 않았다.
