# ADR-0004: 초기 API 예산과 키

- 상태: 확정
- 결정자: 개인(프로젝트 사용자)
- 날짜: 2026-10-27
- 근거: Q4 A; 제안서 §4.1·§4.3, 사용자 A안 채택 답변. [초기 질문 기록](../open-questions.md)

## 배경
제안서 토큰 수치는 사용량 예시이며 예산·결제 책임은 미정이었다.

## 선택지
A: 초기 유료 호출 0원·사용자 키 나중 연결 / B: 사용자 계정 소액 실호출 / C: 학교·팀 계정

## 선택한 이유
비용 없이 초기 하네스를 정리하고 실제 연동은 나중에 검증하려고 A를 채택했다.

## 영향
초기 유료 호출 예산은 0원이다. 키는 개인이 관리하고 연결·API 호출은 보류한다. 키 값을 문서·채팅·로그·커밋에 넣지 않는다. 향후 로컬 환경변수나 미추적 .env를 사용하고 예제에는 빈 값만 둔다. 실제 연동 전 비용·연결 결정과 당시 공식 가격 확인이 필요하다. 실제 API 품질은 아직 검증하지 않았다.
