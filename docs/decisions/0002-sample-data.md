# ADR-0002: 초기 테스트 자료

- 상태: 확정
- 결정자: 개인(프로젝트 사용자)
- 날짜: 2026-10-27
- 근거: Q2 A; 제안서 §3.1·§6, 사용자 A안 채택 답변. [초기 질문 기록](../open-questions.md)

## 배경
초기 목표는 텍스트 PDF 3개 이상이며 실제 테스트 자료는 아직 없었다.

## 선택지
A: 직접 만든 비민감 텍스트 PDF 3개 / B: 권리 확인한 공개 PDF / C: 지정 개인 학습자료

## 선택한 이유
자료의 권리·내용·정답을 통제하고 초기 평가 준비를 단순하게 하려고 A를 채택했다.

## 영향
초기 자료는 직접 만든 비민감 텍스트 PDF 3개로 제한한다. 제작 시 작성 출처·식별자·정답 페이지를 기록한다. 실제 강의자료의 복잡성은 덜 반영한다. 이번 P2에서는 PDF를 제작하지 않는다.
