# ADR-0003: 외부 전송 허용 범위

- 상태: 확정
- 결정자: 개인(프로젝트 사용자)
- 날짜: 2026-10-27
- 근거: Q3 A; 제안서 §3.1·§4.2·§6, 사용자 A안 채택 답변. [초기 질문 기록](../open-questions.md)

## 배경
OpenAI 임베딩·생성은 관련 텍스트 전송을 수반하므로 허용 자료 범위가 필요하다.

## 선택지
A: 권리·전송 허용 확인한 비민감 샘플만 / B: 익명화·권리 확인한 개인 자료까지 / C: 외부 전송 금지

## 선택한 이유
제안서 구조를 유지하면서 초기 데이터 노출 범위를 제한하려고 A를 채택했다.

## 영향
Q2 자료 중 권리·전송 허용을 확인한 비민감 샘플만 향후 전송 대상으로 허용한다. 개인·기밀·비공개 자료는 초기 대상에서 제외한다. 이는 실제 전송 실행 승인이 아니다. 연결·실호출은 ADR-0004에 따라 보류한다. API 보관 정책은 제안서만으로 확정하지 않는다.
