# 의사결정 기록(ADR)

채택 정책의 기준 정보는 이 폴더의 ADR이다. [개요](../project-brief.md)는 요구와 근거를, [초기 질문](../open-questions.md)은 당시 선택지·답변 이력을 보존한다.

## 개인 확인이 필요한 기준
다음 변경은 실행 전에 개인의 결정을 받는다.
- Python·프레임워크·모델·패키지 관리 등 주요 기술 스택 변경
- 데이터 출처·민감도·전송 범위·저장 방식·보관/삭제 정책 변경
- 유료 호출·구독·예산 상향 등 비용 발생
- 새 외부 서비스 연결, 키 등록, 데이터 전송 실행
- 기능·단계·배포·인증 등 프로젝트 범위 변경

동일 정책 아래의 오탈자·문서 링크·사소한 파일 정리와 가역적인 구현 세부 선택은 매번 승인받지 않는다. 기존 Q1~Q5는 재확인하지 않는다. 다만 비용 0원·전송 보류 등 확정 경계를 넘는 실행은 새 결정이다. 불명확한 경우 영향과 선택지를 제시하고 의존 작업만 기다린다.

## 기록 방법
파일명은 순번과 주제를 쓴다. 필수 항목은 상태(제안/확정/보류), 배경, 선택지, 선택한 이유, 영향, 결정자, 날짜다.
AI는 미확정 정책을 제안으로 작성하고 개인 답변이 있을 때 확정으로 바꾼다. 답변이 없으면 확정하지 않는다. 확정 ADR의 정책을 바꿀 때는 새 ADR을 만들고 이전 기록에 대체 관계를 연결한다.
날짜는 개인의 결정 날짜를 사용한다. 작성된 문서의 개인 채택과 기존 정책 확정은 구분한다.
