# 개인과 AI의 작업 흐름

이 문서는 이번 P2에서 제안한 운영 절차다. 개인이 최종 채택하며, 오늘은 문서 작성·검사까지만 수행한다. 작업 규칙은 [AGENTS.md](../AGENTS.md), 중요 결정 기준은 [결정 목록](decisions/README.md)을 따른다.

## 책임과 역할
이번에는 한 CLI 세션에서 AI가 작성자와 검토자를 순서대로 맡는다. 병렬 에이전트나 별도 검토자를 전제하지 않는다. 같은 AI의 역할 전환은 독립 검토를 보장하지 않으며 최종 판단은 개인이 맡는다.

| 역할 | 입력 | 출력 | 수정·판단 범위 |
|---|---|---|---|
| 개인 | 요청·제안서·변경 계획·중요 결정 선택지·검사 보고 | 목표·범위 확정, 중요 결정 답변, 최종 채택/수정/보류 | 범위·정책·비용·최종 채택 결정, 흐름 관리 |
| AI 작성자 | 요청·기존 파일·확정 ADR·계획·검토 지적 | 최소 변경 파일, 변경 이유, 검사 증거, 미정 목록 | 승인된 요청 범위의 파일만 수정. 원문·비밀·범위 밖 기능은 건드리지 않음 |
| AI 검토자 | 요청·변경 파일·원문 근거·검사 결과 | 충돌·누락·링크·범위 위반 판정과 수정 요청 | 먼저 읽기·검사만 수행. 수정 필요 시 작성자로 돌아가 수정 횟수 기록 |

## 순서와 산출물
1. **요청 확인:** 개인의 목표·단계 상한·금지 작업을 작성자가 확인한다. 파일명·확장자·기존 문서도 실제 확인한다. 출력은 이번 작업 범위다.
2. **영향과 계획 정리:** 영향 파일·충돌·검사 방법을 정리해 알린다. 기존 사용자 변경을 보존한다.
3. **중요 결정 개인 확인:** ADR 기준에 해당하는 미확정 결정만 선택지·장단점·추천 이유와 함께 묻는다. 답변 전 해당 결정에 의존하는 실행은 보류하되 독립 작업은 계속할 수 있다. 이미 채택한 결정을 반복 질문하지 않는다.
4. **작업:** 작성자가 허용된 파일만 수정하고 근거·결정 상태를 구분한다. 작은 파일 정리마다 승인을 받지 않는다.
5. **검사:** 검토자로 전환해 요청 충족·근거·범위·링크·명령 상태·비밀 노출을 확인한다. 기능 단계에서는 [테스트 계획](testing.md)에 따른다.
6. **문서 갱신:** 작성자가 기준 문서와 관련 링크를 갱신하고 검토자가 다시 일관성을 확인한다. 변경·검사 결과·미검사·미정을 보고한다.
7. **개인 채택:** 개인이 결과를 채택·수정 요청·보류한다. AI의 검사 통과나 문서 생성만으로 개인 채택을 기록하지 않는다. 다음 단계로 자동 진입하지 않는다.

## 실패와 중단
최초 검사 실패 후 작성자에게 돌아가 추가 수정→재검사를 최대 2회 수행한다. 같은 작업의 제한을 역할 변경이나 검사 명칭 변경으로 초기화하지 않는다.
계속 실패하면 원인, 영향 파일, 수행한 수정 1·2회, 남은 실패, 다음 조치·필요한 개인 입력을 보고하고 해당 작업을 중단한다. 성공하지 않은 검사를 성공으로 적지 않는다. 환경 미구성은 미실행/차단으로 기록하며 설치를 임의 진행하지 않는다.

## 권한과 기록
규칙 파일만으로 도구 권한이 강제되지는 않는다. 실제 도구 권한·샌드박스·승인 설정을 별도로 따른다. 개인의 정책 채택이 도구의 권한을 넓히지는 않는다.
결과에는 변경 경로, 검사와 실제 결과, 수정 횟수, 미정·잔여 위험, 개인 채택 대기 여부를 남긴다. 중요 정책 변경은 후속 ADR로 기록한다.
